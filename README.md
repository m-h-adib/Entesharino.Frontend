# Entesharino Frontend

Frontend for Entesharino using Next.js, TypeScript and Tailwind CSS.

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- RTL / Persian UI

## Development

```bash
npm install
npm run dev
```

Set the backend URL in `.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000
```

The backend API is maintained in the separate `m-h-adib/Entesharino` repository.
